# API TotalPlay
API REST para gestionar clientes, servicios y paquetes de internet de TotalPlay.

**Integrantes:**
- Dylan Isaí García Tovar
- Mario Axel Alemán Rangel

## Cómo ejecutarlo

1. Clonar el repositorio:
```
   git clone https://github.com/dylangarcia-edu/totalplay-api.git
   cd totalplay-api
```
2. Instalar dependencias:
```
   pip install -r requirements.txt
```
3. Iniciar el servidor:
```
   python -m uvicorn app.main:app --reload
```
4. Abrir en: http://127.0.0.1:8000/docs
